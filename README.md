# Pangolin

## Comandos para instalar el script:

```
$ curl -fsSL https://static.pangolin.net/get-installer.sh | bash

$ sudo ./installer
```
<br>

NOTA. Mira antes la versión actual: https://docs.fossorial.io/Getting%20Started/quick-install
